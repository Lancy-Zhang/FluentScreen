# Install FluentScreen on macOS

## Requirements

- macOS 13 or later
- Google Chrome

## Steps

1. Open `FluentScreen-1.5.0-macOS.dmg`.
2. Double-click **Install FluentScreen**. If macOS blocks it, right-click it and choose **Open**.
3. The installer copies FluentScreen Vision and the Chrome extension into `~/Library/Application Support/FluentScreen/`.
4. Chrome opens `chrome://extensions`. Turn on **Developer mode**.
5. Click **Load unpacked** and select the folder revealed by Finder: `Chrome Extension`.
6. Open a supported video, click the FluentScreen toolbar icon, and keep the side panel open.

The extension starts FluentScreen Vision automatically when OCR is needed. You may quit the helper when you are not using hardcoded subtitle recognition.
