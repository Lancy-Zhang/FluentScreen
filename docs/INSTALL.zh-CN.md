# 在 macOS 安装 FluentScreen

## 系统要求

- macOS 13 或更高版本
- Google Chrome

## 安装步骤

1. 打开 `FluentScreen-1.5.0-macOS.dmg`。
2. 双击 **Install FluentScreen**。如果 macOS 阻止打开，请右键它并选择“打开”。
3. 安装程序会把本地识别助手和 Chrome 扩展复制到 `~/Library/Application Support/FluentScreen/`。
4. Chrome 会打开 `chrome://extensions`，请打开右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择 Finder 自动显示的 `Chrome Extension` 文件夹。
6. 打开支持的视频页面，点击 FluentScreen 扩展图标，并保持侧边栏开启。

需要识别画面硬字幕时，扩展会自动启动 FluentScreen Vision。不使用画面字幕识别时，可以关闭这个本地助手。
