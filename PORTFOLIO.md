# FluentScreen — Portfolio Copy / 作品集文案

## Resume — English

**FluentScreen | AI Product Developer (Independent Project)**  
Designed and built a local-first bilingual video learning product that combines a Manifest V3 Chrome extension with a native macOS Apple Vision OCR companion. Implemented subtitle extraction, hardcoded-caption recognition, deduplication, playback synchronization, persistent Chinese–English transcripts, translation caching, sentence explanations, and vocabulary collection. Packaged the product as a shareable macOS DMG with Native Messaging integration and bilingual documentation.

**Tech:** JavaScript, Chrome Extension MV3, Objective-C, Apple Vision, Native Messaging, HTML/CSS, AppleScript
